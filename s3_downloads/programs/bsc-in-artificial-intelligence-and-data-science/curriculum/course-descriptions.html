B.Sc./B.S. in Data Science & Artificial Intelligence - Course Descriptions

 

Data and the World (1 Credits)

Data & datasets, usage of data in everyday life, examples of real-world applications that use data, how data is made available, how data is used by applications, how not to use data. Case Studies

Supervised Learning (3 Credits)

Linear Regression, Logistic Regression, Naive Bayes, Decision Trees, SVM, kNN; Perceptron and ANN; Loss functions, optimizations, regularization, hyperparameter tuning as applicable, Model evaluation techniques.

Fundamentals of Data Science and Engineering (3 Credits)

Types of Data and Datasets, Data Quality and Issues: An overview, Data Models, Data Pipelines and patterns; Data Pipeline Stages, Process Models, Data Analysis with Statistical Tools (such as R). Simple Statistical Models.

Data Preprocessing (3 Credits)

Feature Engineering (feature extraction, missing data, creating new features, encoding, feature selection), correlation matrices, Dimensionality Reduction: PCA and SVD, Anomaly detection and outlier detection. Handling skewness, Normalization, Sampling

Unsupervised Learning (3 Credits)

Introduction to Unsupervised Learning: Applications and Challenges; Clustering: Partitioning-based Clustering, Hierarchical Clustering, Density-based Clustering, Clustering using Gaussian Mixture Models, Clustering Evaluation Metrics; Anomaly Detection Methods. Association Rule Learning: Apriori and FP-Growth algorithms, Market Basket Analysis.

Mobile and Web Application Development (3 Credits)

Introduction to Mobile and Web Development; Platforms (Web, Mobile platforms such as iOS/Android) and development environments; Frontend Development: HTML, CSS, JavaScript basics; Front-end and Back-end Frameworks; Basics of server-side programming; RESTful API design and development; Mobile App Development Basics: Native vs Hybrid apps, Integrating with Databases: Relational databases (e.g. MySQL), NoSQL databases (e.g. MongoDB); Authentication and Security using basic frameworks (e.g.OAuth, JWT, and session management; Hosting web apps on platform (e.g. Heroku, AWS); Publishing mobile apps on App Store and Google Play; Using public APIs like Google Maps, Stripe, Spotify, Twilio, etc. to build Apps; End-to-end development of a mobile and/or web app.

Data Structures for Data Science (3 Credits)

Introduction to time Complexity; Introduction to fundamental data structures and their usage: Arrays, Linked Lists, Stacks, Queues, Priority Queues; Dictionaries and Hashing: Hash Tables and Bloom Filters, and Applications; Searching and Sorting; Binary Trees and Introduction to Optimization Formulation of linear programming problems, Simplex method, Sensitivity analysis, Revised and Dual Simplex Methods. Introduction to Convex Optimization Binary Search Trees; Disk-based Structures; Nearest Neighbor Search and Optimization using kd-trees; Data Structures for Streaming: Sketching, Summarization and real-time processing; Tries for text processing. Compressed Tries. Prefix and Suffix Trees

Linear Algebra (? Credits)

Vector and matrix algebra, systems of linear algebraic equations and their solutions; eigenvalues, eigenvectors and diagonalization of matrices, SVD

Optimization (2 Credits)

Introduction to Optimization Formulation of linear programming problems, Simplex method, Sensitivity analysis, Revised and Dual Simplex Methods. Introduction to Convex Optimization

Computing Systems (3 Credits)

Understanding of a Computing System and Environment for day-to-day programming activities. Generic structure of a computer. CPU (cache, memory hierarchy, threads and multi-core processors), GPU (memory hierarchy, threading model), Isolation (containers), Distributed Computing (client-server, clusters, data partitioning), Cloud (Virtualization, containers, scalability), Programming Environments (Code Repositories and Versioning Systems), Execution Environments (Shell Commands, Scripting, profiling and debugging)

Computer Programming (2 Credits)

Introduction to Computing and Computers; Introduction to Programming Languages; Flowcharts and Algorithms; Number System; Basics of Python: Syntax, variables and data types; Control Structures: Conditionals (if, elif, else) and loops (for, while); Functions: Defining, calling, arguments, return values, and scope; Data Structures: Lists, tuples, sets, dictionaries, and strings; File Handling: Reading from and writing to files; Modules and Libraries: Importing and using standard libraries (e.g., math, random, os); Basic Algorithms: Searching (linear, binary) and sorting (selection), Max, Average and Median; Introduction to NumPy: Basic array manipulations

Multivariable Calculus (3 Credits)

Review of Limits, Continuity, differentiation and integration, introduction to multivariable calculus, partial derivatives, Multiple Integrals.

Classical AI (3 Credits)

Search Techniques for Problem Solving: Branch and Bound, Heuristic Search: Hill Climbing, Simulated Annealing, A*; Knowledge Representation: First-Order Predicate Logic, Frames, Semantic Web; Knowledge Graphs; Intelligent Agents 

Deep Neural Networks (3 Credits)

Basic ANNs, Back Propagation and Forward Propagation, RNNs and LSTMs, CNNs, Segmentation (SAM, SAM2), models for segmentation, Popular Architectures (Yolo, UNet)

Combinatorics (2 Credits)

Sets, Functions, and Relations. Counting - Permutations and Combinations. The Pigeonhole Principle and its applications. Recurrence Relations and Basic Solution Approaches.

Search Engines (2 Credits)

Structure and components of Classic Search Engines; Building a Crawler, Indexing of Text and Multimedia Data, Retrieval, and Ranking; Web as a graph, Link analysis, Pagerank and HITS; Assembling a search engine end-to-end given a crawler, Multilingual and cross lingual retrieval systems

Multimedia Processing (2 Credits)

Understanding of Multimedia Processing, image/audio/video representation, compression, transformation to feature vectors, Multimedia Analytics (segmentation, classification using KNN and SVM for image and videos, and HMM and GMM for audio data)

Data Visualization (3 Credits)

Visualization design objectives (charts, graphs, hierarchical layouts, and techniques for visualization of high dimensional data); Understanding the context for data presentations, 3-minute story, Effective Visuals, Gestalt principles of visual perception, Visual Ordering, Decluttering, Story Telling, Usage of Visualization Tools (e.g. Tableau, PowerBI, and matplotlib), Dashboard and Stories.

Modern Databases (3 Credits)

NoSQL databases - Querying unstructured and semi-structured data; BASE model. Distributed Databases. Eventual Consistency and Chubby Locking. Joins, Indexing, CAP Theorem and database design, Analytics using modern databases.

Relational Databases and Querying (3 Credits)

Data Modelling - ER diagrams; ACID properties, Functional Dependencies, Database Design - normalization and normal forms; Querying - SQL, Joins, understanding of query performance, manual optimization of queries; Analytics using relational databases

Healthcare Data Analytics (same as in MSc) (3 Credits)

Types and characteristics of data in healthcare; EMR; EHR-understanding data schema and representation; Health Management Information Systems (Clinical Information Systems, Management Information Systems, Decision Support Systems, EMR Systems, Health Information Exchange, Telehealth Systems); Health statistics; EDA in healthcare; Descriptive and predictive analytics in healthcare; Data ownership and emerging data governance models in healthcare

Analytics for Retail & eCommerce (3 Credits)

Introduction to retailing and e-Commerce; Introduction to retail analytics; Demand estimation; Customer segmentation; Customer lifetime value; e-Commerce analytics value chain; Methods and techniques for e-Commerce analytics; Analysing behavioral data

Application Deployment on the Cloud (3 Credits)

Model inferencing, Basic deployment, Containerization (e.g. Dockers), Orchestration of multiple containers (e.g. Kubernetes), deployment of data/ML applications on the cloud, Serverless deployment (e.g. AWS Lambda)

Analytics for BFSI (3 Credits)

Digital economy, digital identity; Role of cloud computing, big data and blockchain in the fintech ecosystem; Financial services disruptions (asset servicing, capital markets, investment management, insurance); Data sourcing for analytical models; AI applications in finance, machine learning in finance, text mining, generative AI, financial market analysis; Regulatory technology (RegTech); Open banking, Bank 4.0; Financial sector transformation

Devices and Networks (3 Credits)

What is IoT; Key elements of an IoT system - sensors, actuators, communication & networking, data storage, software application; IoT and big data; Benefits of integrating IoT with ML, examples from sectors such as industrial IoT, agriculture & healthcare; Trade-offs in end-to-end ML applications in IoT systems with examples

Capstone Project (12 Credits)

An advanced project that students typically complete at the end of the academic programme or after completion of substantial part of the programme. It showcases their ability to apply what they've learned to a real-world problem or research topic

Keystone Project (12 Credits)

An advanced project that students complete at the end of the academic programme. It demonstrates their ability to solve real-world problems as applied to specific business verticals or domain areas

Apex Project (1 or 2 Credits)

A high-level project that represents the culmination of a student’s learning experience at the end of a trimester

Introduction to Text Analytics (3 Credits)

Introduction to text analytics; Text data: structured vs unstructured; pre-processing: tokenization, stemming, lemmatization, and part-of-speech tagging. Representation techniques - Bag-of-Words, TF-IDF, Word2vec, GloVe, etc; Hands-on with popular tools and libraries; Solving NLP tasks on real datasets - text classification, summarization, named entity recognition, recommender systems, topic mining.

Governance in AI (3 Credits)

Fairness & Inclusivity, Ethics, Transparency, Explainability, Regulatory Compliance, Data Protection, Data Privacy, Anonymization. Case Studies; Solutions to address ethical issues for government, corporations/organizations, research, public use of data, social norms, and legal compliance; Case studies. Data ethics in specific domains - e.g. health care, finance, and social studies/research.

Advanced Deep Learning (3 Credits)

Autoencoders, GANs, Transformers, Diffusion Models, Hyper-parameter tuning, Introduction to LLMs, and VLMs. Overview of GenAI and applications.

Data Warehousing and Data Lakes (3 Credits)

Multidimensional Relational Data, Data warehouses; Column-wise storage, ETL vs ELT, Common storage for structured and unstructured data. Datastore for raw data. Data Warehouse vs Data Lakes, Data Ingestion, Data Pipeline, Analytics using relational data warehouses and data lakes.

Big Data Analytics (3 Credits)

Parallel and Distributed Architectures for Big Data; Data Distribution Techniques; Resilience (Data + Compute) - MapReduce, In-Memory Distributed Processing and RDDs (e.g. Spark); Structured Big Data Systems and Querying (e.g. BigTable) Stream processing (e.g. Apache Storm)

Software Engineering and AI (3 Credits)

Agile processes, Software design, Code automation using GenAI, Software testing; Testing using GenAI; ML Techniques for Test Case Generation; ML Techniques for Code Coverage

Graph Algorithms (3 Credits)

Konigsberg bridge problem; walk/paths, and isomorphism; Attributes/Properties: centrality - degree / betweeness / eigenvector centrality / eccentricity, adjacency degree matrices, Laplacian, spectral components; Graph traversal and path finding methods: BFS, DFS, Dijkstra's, Bellman–Ford, Floyd–Warshall; Popularity Ranking: PageRank, HITS. Graph construction mechanisms: NN similarity graphs, graph kernels, proximity graphs, Link Prediction-Jacard Coefficient, Adamic adar, Katz

Cloud Services & Platforms (3 Credits)

Introduction to Cloud Computing: History and evolution of cloud computing, Key characteristics and service models (IaaS, PaaS, SaaS), Cloud deployment models (Public, Private, Hybrid, and Multi-cloud); Cloud Platforms: Overview of major cloud platforms: AWS, Microsoft Azure, Google Cloud Platform (GCP), Introduction to platform-specific tools and services; Virtualization and Networking: Concepts of virtualization and virtual machines, Containers and orchestration with Kubernetes/docker, Software-defined networking (SDN) and virtual private clouds (VPCs); Cloud Storage and Databases: Types of cloud storage: Object, Block, and File storage, Managed database services: Relational and NoSQL databases, HDFS; Backup, recovery, and disaster recovery in the cloud; Cloud Security and Compliance: Identity and Access Management (IAM), Encryption and data protection strategies, Compliance standards: GDPR, HIPAA, ISO 27001, Threat detection and response; DevOps and Automation in the Cloud: Introduction to DevOps and its importance in cloud environments, CI/CD pipelines and deployment automation, Infrastructure as Code (IaC) with tools like Terraform and AWS CloudFormation.

Soft Computing (3 Credits)

Fuzzy Logic - Membership Functions, Fuzzification, and Defuzzification, Fuzzy Reasoning. Fuzzy Classification. Expert Systems; Evolutionary Algorithms; Genetic Algorithms- Chromosomes, Fitness Functions, and Selection mechanisms, Crossover and Mutation; Genetic Programming; Other related approaches such as Ant Colony Optimization, Swarm Intelligence Algorithms.

Distributed Systems for (Model) Training (3 Credits)

Overview of Distributed Systems and Clusters; Data Transfer / Communication Performance and Constraints; Data Parallelism vs. Task Parallelism; Distributed SGD - Performance issues and solutions; Data Distribution techniques; Distributed Machine Learning Platforms and Architectures (e.g. TensorFlow, Apache Spark)

Graphs and AI (3 Credits)

Many-to-Many Relations, Graph Data Stores and Graph databases, (e.g. Neo4j), Querying Graph Databases. Graph clustering and Graph Classification. Knowledge Graphs and Applications. Querying Knowledge Graphs. Ontologies. Semantic Entailment. Graph Analytics. Knowledge Graph Embeddings

ML on Edge (3 Credits)

Overview of Distributed AI and ML; ML on IoT Networks; Data distribution for ML models and inference on IoT; ML on Small Form Factor devices - Constraints, Compressed Models; Tradeoffs between ML performance and System Performance; Federated Learning

Big Data Engineering (3 Credits)

Basic performance measurement and analysis using python profiler; Measuring impact of Locality, caching, IO latency, bandwidth, network latency; Optimizing performance and Handling Big Data; Data movement, Memory Latency, and GPUs, Leveraging GPUs, Leveraging Distributed Systems., Data Partitioning;

ML for Data Streams (3 Credits)

Stream Processing – abstractions, platforms, and programming interfaces used for processing streams, windowing / micro-batching techniques. Case studies and applications. Stream Processing Platforms (e.g. Kafka, Apache Flume, Spark and Storm); Platform architectures (such as Alpha and Kappa Architectures) for Mixed Processing.

Generative AI Applications (3 Credits)

Prompt Engineering and Coding Prompts; Building Applications using Generative AI; Retrieval Assisted Generation (RAG); KV Caching and Content Assisted Generation (CAG); Evals and Domain Fitting; Design and development of industry solutions using agents-powered Generative models; in single and multi-agents environments (e.g. CrewAI, AutoGen, LangGraph, Open AI Swarm); Application Case Studies - Chatbots and Virtual Assistants, Tutoring Systems, Game Development, AR/VR;

Robotics and AI (3 Credits)

Fundamentals of robotics, Mapping and localization algorithms, path planning algorithms, Instance-based learning, demonstration-based path planning using reinforcement learning, deep learning and reinforcement learning based mapping, navigation and control of mobile robots.

Multimedia Analytics (3 Credits)

Multi-modal Search, Recommendation, Domain Specific Applications, image annotations; 3d image content analysis- traffic analysis, human action recognition

AI Application Deployment (3 Credits)

DevOps & CI/CD (e.g. Jenkins, Github Actions); Scripting; Data pipelines and workflow automation; Unique challenges in data science and AI projects; MLOps

Cloud-Native AI (3 Credits)

Introduction to Microservices; Software Design using Microservices; Cloud Platforms and APIs for AI/ML (e.g. AWS and Azure APIs), AIML Applications on Cloud Platforms using Native APIs (e.g. AWS and Azure)

Foundations of Generative AI (3 Credits)

Mathematical background- Probability Distributions, Discrete and Continuous modelling; Generative vs Discriminative models; Evolution of Gen AI models-Bayesian networks, Autoregressive Models, Autoencoders and Variational Autoencoders, GANs, Deep generative models; Understanding of different types of deep generative models with applications- Large language models, visual language models and graph language models,

Applications-Adversarial training, Synthetic data generation, AI-GeneratedMusic/Avatars, visual Q&A task etc.; Latest research trends in generative AI;

NLP Applications (2 Credits)

Sentiment Analysis, Grammar and Spelling Checkers, POS Tagging, Question answering and Chatbots, Information Extraction (named entity recognition, relation extraction)

Programming using Generative AI (1 Credits)

GenAI based Programming Tools; Code Completion and Code Generation using LLMs; Debugging Generated Code; Fixing errors and Testing Generated Code
