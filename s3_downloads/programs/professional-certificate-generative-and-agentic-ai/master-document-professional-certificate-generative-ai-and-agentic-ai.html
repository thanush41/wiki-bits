Professional Certificate in Generative & Agentic AI | Updated for December 2026 Cohort

1. PROGRAM OVERVIEW

 

Program Objective

From the December 2026 cohort, the Professional Certificate in Generative & Agentic AI is a single-track, ~35-week program: every learner starts with a built-in 5-week foundation in Python and cloud, then moves through the AI curriculum. 

The AI curriculum focuses on:

  • Large Language Models (LLMs)
  • Retrieval-Augmented Generation (RAG)
  • AI agents and agentic workflows
  • Evaluation and deployment of AI systems
  • Production-like readiness
  • Responsible and governed use of AI systems
  • Capstone-based demonstration of real AI work

3. Eligibility criteria

Applicants must hold a bachelor's degree from a recognised university and should have studied Mathematics in Grade 12. Applicants should be comfortable writing basic programs in at least one programming language, gained through work, academic study or personal projects. Work experience in software development, data, analytics, cloud, AI/ML, IT or allied fields is preferred but not mandatory, and recent graduates are welcome to apply.

Note: All applicants are required to submit a Programming Proficiency Declaration as part of the application form.

What the declaration confirms. The applicant has a working proficiency in at least one programming language and can:

  • independently read, understand, write, and modify basic programs;
  • use variables, data types, conditional statements, loops, functions, and basic data structures;
  • translate a simple problem or requirement into working code;
  • identify and resolve basic errors in code through debugging; and
  • write and execute small programs or scripts without step-by-step instruction.

The applicant also acknowledges that the program assumes this level of proficiency. The foundation weeks help learners transition to Python and the cloud tools used in the program; they are not designed to teach programming from the beginning.

4. Curriculum overview

The program has seven modules. Module 1 now runs for 8 weeks in three parts, each ending in a clear learner win, before every learner moves on to the AI modules together.

Module 1: Foundations of AI Development

Module 1 begins with a 5-week foundation in Python and cloud (AWS), then introduces the foundations of AI application development through Git, Docker, LLM concepts, and Responsible AI. Learners build a command-line LLM application and a Dockerized FastAPI REST API with a simple Streamlit web interface, deployed on AWS.

Tools you'll use: the AI systems stack

The program is built around selective tool depth, not tool overload. Learners use each tool where it fits in a production AI system, then build with it across the labs and capstone.

5. Learning methodology

The program follows a flipped-classroom model: learners build understanding through self-paced videos and labs during the week, then use live sessions for instructor interaction, demos, doubt resolution and deeper discussion.

 

 

 

6. Assessment and certification

  • To receive the certificate, learners must complete all quizzes and the capstone project with at least a "fair" grade.
  • The certificate is the "Professional Certificate in Generative & Agentic AI" from BITS Pilani Digital, issued in the learner's name.
  • It is a non-degree, non-credit professional certificate; it does not count towards a BITS Pilani degree.

 

7. Fee, EMI and refund

Additional costs learners should expect. Most tools are free and open source. Out-of-pocket spend is approximately ₹16,000–30,000 across the program (about ₹2,000–3,500 a month), mainly for LLM API usage, an AI coding-assistant subscription and AWS cloud usage. Learners manage these accounts directly; LLM API keys and spending limits are set up in Week 1, and AWS budgets during the foundation weeks.

8. WEEKLY TIME COMMITMENT
